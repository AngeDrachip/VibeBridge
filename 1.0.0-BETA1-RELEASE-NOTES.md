- **Horizon Mod Installation**:
  - `vibe horizon install` command to copy `.hmod` to `<game-dir>/horizon-mods/`

## Known Issues

### 1. Java Code Limitations
- Horizon content mods cannot execute Java code (Mixins, coremods, access transformers)
- Java item registrations (using `@ObjectHolder`, `@EventBusSubscriber`, etc.) are not carried into Horizon content bundles
- Only data and asset files (JSON models, textures, recipes) are exported from Forge mods

### 2. Version Compatibility
- Horizon targets Minecraft 26.3 specifically
- Forge 26.3 (66.1.x) is the compatible Forge version
- Minecraft versions outside 26.3.x will not work with Horizon

## Getting Started

### Prerequisites
1. Minecraft Java Edition 26.3 installed
2. Forge 26.3 (66.1.x) installed
3. Horizon launcher v0.2.97 installed
4. VibeBridge 1.0.0-beta.1 installed

### Installation Steps
1. Download and install Horizon launcher from official GitHub
2. Download and install VibeBridge 1.0.0-beta.1
3. Launch Horizon client
4. Use `vibe horizon connect` to verify connection
5. Use `vibe horizon export` to export Forge mod
6. Use `vibe horizon install` to install into Horizon game

## Known Issues

- **Java Code Not Carried**: Java code (items, blocks, events) is not included in Horizon content bundles
- **Namespace Conflicts**: Items with conflicting namespaces may not render properly
- **Resource Packs**: Resource packs are not supported in Horizon content mods
